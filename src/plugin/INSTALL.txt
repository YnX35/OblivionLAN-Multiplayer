OblivionLAN — prototype de connexion LAN intégré à xOBSE
Cible : The Elder Scrolls IV: Oblivion classique, Steam, xOBSE, Win32.

ÉTAT EXACT
Cette version démarre un hôte TCP ou se connecte à un hôte LAN depuis le jeu.
L'hôte peut accepter jusqu'à trois clients distants (quatre joueurs au total,
hôte compris). Les connexions sont gérées dans des threads réseau séparés.
Le handshake vérifie le protocole OLAN version 1.
IMPORTANT : il s'agit encore d'un prototype expérimental, pas d'un multijoueur jouable.
Le code tente de créer et déplacer un proxy d'avatar distant dans la même cellule,
mais ce comportement n'a pas encore été validé en jeu ni sur des sauvegardes.
Aucun combat, créature, objet ou quête n'est synchronisé. Ne pas installer sur
une sauvegarde importante ; attendre la validation des tests en jeu.

INSTALLATION
1. Fermer Oblivion sur les deux PC.
2. Dans le dossier du jeu, ouvrir Data\\OBSE\\Plugins (créer les dossiers s'ils manquent).
3. Copier OblivionLAN.dll dans Data\\OBSE\\Plugins.
4. Copier OblivionLAN.ini.example dans le même dossier et le renommer OblivionLAN.ini.
5. Sur le PC hôte, régler Mode=host. Sur chaque PC client, régler Mode=client
   et Host= avec l'adresse IPv4 LAN du PC hôte.
6. Pour Steam, xOBSE doit être installé dans le dossier racine du jeu, avec
   obse_steam_loader.dll à côté de Oblivion.exe. Lancer Steam puis Oblivion
   depuis Steam ou directement avec Oblivion.exe.
7. Démarrer le jeu hôte en premier, attendre le message d'écoute dans
   OblivionLAN.log, puis démarrer les clients.
8. Consulter OblivionLAN.log dans Data\\OBSE\\Plugins sur chaque PC.

CONFIGURATION HÔTE
[Network]
Mode=host
Host=127.0.0.1
Port=47621

CONFIGURATION CLIENT
[Network]
Mode=client
Host=192.168.1.XXX
Port=47621

Remplacer 192.168.1.XXX par l'adresse IPv4 réelle du PC hôte.
Les deux PC doivent être sur le même réseau local. Autoriser Oblivion dans
le pare-feu Windows sur le réseau privé si nécessaire. Ne pas exposer le port
à Internet. Jusqu'à trois clients peuvent se connecter à un hôte.

DÉPANNAGE
- Mode=disabled désactive le réseau sans désactiver le plugin.
- « host bind/listen failed » : le port est peut-être déjà utilisé.
- « could not connect » : vérifier l'adresse, que l'hôte écoute, et le pare-feu privé.
- « invalid or timed-out handshake » : vérifier que les deux PC utilisent le même build.
- Si xOBSE ne se charge pas sur Steam, vérifier obse_steam_loader.dll dans le
  dossier racine et activer l'overlay Steam. Redémarrer Steam peut aider.
- Les messages réseau sont consignés dans OblivionLAN.log.
- Pour désactiver le réseau, remettre Mode=disabled puis relancer le jeu.

SÉCURITÉ ET LIMITES
Tester sur une copie de sauvegarde. Ne pas utiliser une sauvegarde importante
pour les premières validations. Le LAN n'est pas une frontière de sécurité :
ne pas ouvrir le port sur Internet. Un build réussi ne prouve pas le chargement
ou la compatibilité en jeu. Cette version ne crée aucun personnage visible.
